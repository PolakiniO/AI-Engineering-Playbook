# Product Bundles

AI-Engineering-Playbook is currently focused on free distribution and remains
MIT-licensed. The bundles below make the open skills easier to discover, install,
and evaluate.

## Production Code Review Guardrails

Architecture, interface contracts, safety boundaries, and risk-based testing:

- `architecture-guardian`
- `artifact-contract-reviewer`
- `scope-safety-guard`
- `test-strategy-reviewer`

Free install:

```bash
npx skills add PolakiniO/AI-Engineering-Playbook
```

Current goal: publish and validate this bundle through free directories and
real-world open-source usage.

## AI Engineering Delivery Playbook

Planning, security, deployment, operations, cost, and agent orchestration:

- `project-engineer`
- `security-engineer`
- `deployment-engineer`
- `operations-engineer`
- `finance-engineer`
- `codex-agent-orchestration`

Current goal: publish and validate this bundle through free directories and
real-world open-source usage.

## What remains free

The repository, canonical skills, generated distribution, examples, and basic
installation guidance remain public. `playbook-installer`, `product-designer`,
`performance-optimizer`, and `llm-output-reviewer` remain free add-ons.

The public smoke cases in [`EVALUATION-PACK.md`](./EVALUATION-PACK.md) document
the verification method and help users evaluate the free distribution.

## Future monetization — deferred

Later options may include repository-specific customization, private overlays,
team onboarding, evaluation packs, maintenance updates, and consulting. No paid
listing or paid packaging is part of the current release plan.
