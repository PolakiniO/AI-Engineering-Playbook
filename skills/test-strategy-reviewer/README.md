# test-strategy-reviewer

Reviews verification scope, regression protection, and risk-based test coverage.

## Install

```bash
bash scripts/setup-codex-skill.sh --skill test-strategy-reviewer
```

From GitHub:

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo PolakiniO/AI-Engineering-Playbook \
  --path dist/codex-skills/test-strategy-reviewer
```

Add `--force` to the local installer if the skill is already installed.

## Use

```text
Use $test-strategy-reviewer to define the minimum safe test plan and regression coverage for this change.
```
